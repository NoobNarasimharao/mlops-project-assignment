# Paper Directory

This directory contains the LaTeX source for the weather‑condition classification assignment.

## Contents
- `main.tex` – LaTeX source of the report (two‑column format).
- `references.bib` – Bibliography file.
- `figures/` – PNG images generated by the experiment:
  - `weather_distribution.png`
  - `model_comparison.png`
  - `random_forest_confusion_matrix.png`
  - `feature_importance.png`

## Building the PDF
Make sure you have a LaTeX distribution (e.g., MiKTeX or TeX Live) with the `IEEEtran` class installed.

From the `paper/` directory run:
```
latexmk -pdf main.tex
```
or the manual sequence:
```
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
The compiled PDF will be written as `main.pdf`.

## Notes
- The figures are copied from the `model/` folder of the project.
- No numbers were altered; all results come from `model/model_results.csv` and `model/model_metadata.json`.
